# Testing

Use this skill when adding tests, repairing failing tests, or verifying a completed implementation.

## Instructions

Inspect the existing test structure before creating new tests.

Follow the repository's current testing conventions instead of introducing a new framework.

When fixing a bug:

1. Reproduce the failure.
2. Identify its actual cause.
3. Make the smallest appropriate change.
4. Run the focused test.
5. Run the broader relevant test suite.

Do not claim that tests pass unless you ran them.

Report the commands you ran and whether they succeeded.
