# Frontend

Use this skill when creating or improving the user interface after the underlying functionality works.

## Instructions

Inspect the existing application and identify its framework before editing.

Preserve the working backend behavior and existing API contracts.

Build the interface around the product's actual purpose rather than creating a generic dashboard.

Prefer:

- Clear hierarchy
- Intentional spacing
- A restrained color palette
- Responsive layouts
- Accessible labels and controls
- Useful empty, loading, and error states

Avoid:

- Excessive gradients
- Unnecessary glassmorphism
- Huge marketing-style headings inside application screens
- Random cards for every piece of content
- Replacing working application logic solely to simplify the UI

Run the application and verify its important interactions after editing.
