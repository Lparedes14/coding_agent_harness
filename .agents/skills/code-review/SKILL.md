# Code Review

Use this skill when asked to review code or a diff.

## Instructions

Review only; do not edit files.

Inspect the changed code and enough surrounding context to understand its behavior.

Report findings first, ordered by severity. For each finding, name the file and line, explain the impact, and suggest a focused correction.

Mention relevant tests that were run or are missing. If you find no actionable problems, say so clearly.
