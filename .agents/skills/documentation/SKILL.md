# Documentation

Use this skill when writing a README, setup instructions, examples, or code documentation.

## Instructions

Inspect the code and configuration before documenting them. Do not invent commands, features, or requirements.

Prefer small, targeted documentation changes in the repository's existing style.

Keep setup steps and examples copy-pasteable. Verify commands when practical, and report what you checked.
