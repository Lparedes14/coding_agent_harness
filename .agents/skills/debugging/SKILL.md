# Debugging

Use this skill when investigating a bug, unexpected behavior, or a failing test.

## Instructions

Reproduce the problem before changing code.

Trace the failure to its actual cause, then make the smallest appropriate fix. Do not change unrelated code.

After the fix, rerun the original reproduction and any nearby tests that could catch a regression.

Report the cause, the change, and the commands or evidence used to verify it.
